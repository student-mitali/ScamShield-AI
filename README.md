# 🛡 ScamShield AI

ScamShield AI is an AI-powered web application that detects scam messages and suspicious URLs. It analyzes text using machine learning techniques and provides a risk score, scam category, explanation, and downloadable PDF report.

---

## Features

- 📩 Scam message detection
- 🌐 Suspicious URL analysis
- 🤖 AI-powered risk scoring
- 📊 Dashboard with scan statistics
- 📝 Scan history
- 📄 Downloadable PDF reports
- 🎨 Modern responsive UI

## Installation

Clone the repository

```bash
git clone <repository-url>
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```
